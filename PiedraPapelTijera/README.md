# Piedra, Papel o Tijera

Juego de piedra, papel o tijera entre dos jugadores.

- Cada jugador saca una ficha al azar con `array_rand`.
- Las fichas se muestran con caracteres especiales (emojis de manos) definidos con `define`.
- La función `calcularGanador` devuelve 0 si es empate, 1 si gana el jugador 1 y 2 si gana el jugador 2.
- Se muestra el mensaje del resultado sacándolo de un array de mensajes.

Archivo: `piedrapapeltijeras-v0.php` (cada vez que se recarga la página se juega otra partida).
