# Ejercicios3-PHP - Arrays en PHP

Boletín de ejercicios de arrays (normales y asociativos).

| Archivo | Ejercicio |
|---|---|
| `01.php` | Array de 20 números aleatorios del 1 al 10: máximo, mínimo y el que más se repite |
| `02.php` | Array asociativo de periódicos (nombre => URL) mostrados como enlaces |
| `03.php` | Elegir al azar uno de los cinco periódicos |
| `04.php` | Array asociativo de deportes con su logo (imágenes en `img/`) |
| `05.php` | Resultado de la bonoloto: 6 números del 1 al 49 sin repetir (el 6º es el complementario) |
| `06.php` | País con más población recorriendo la tabla |
| `06v2.php` | Lo mismo pero ordenando con `uasort` |
| `07.php` | Dos países al azar con `array_rand` y su enlace a Google Maps |
| `08.php` | Tabla HTML con los datos de los países |
| `09.php` | Diagrama de barras con las temperaturas de cada mes |
| `infopaises.php` | Datos de los países que usan los ejercicios 6, 7 y 8 |

La carpeta `img/` tiene las imágenes de los deportes y la barra del diagrama.
