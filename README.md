# 2º DAW - Códigos DWES

Repositorio con los ejercicios y tareas de **Desarrollo Web en Entorno Servidor (DWES)** de 2º DAW en el IES Tetuán de las Victorias (curso 2026-2027).

Todo está hecho en **PHP**, partiendo de los ejemplos y apuntes del profesor.

## Ejercicios

| Carpeta | Qué es |
|---|---|
| [Ejercicios3-PHP](Ejercicios3-PHP) | Ejercicios de arrays en PHP (máximos, bonoloto, países, tabla, diagrama de barras...) |
| [Ejercicios5-PHP](Ejercicios5-PHP) | Funciones de librería: letra del NIF, registro de usuarios con contraseña segura y generador de calendarios |
| [PiedraPapelTijera](PiedraPapelTijera) | Juego de piedra, papel o tijera entre dos jugadores |
| [CincoDados](CincoDados) | Juego de cinco dados entre dos jugadores |
| [Formulario-con-Imagen](Formulario-con-Imagen) | Formulario con validación de datos y subida de una imagen |
| [Ejercicio de Mini Foro](Ejercicio%20de%20Mini%20Foro) | Mini foro con login y análisis del comentario (primera aproximación al MVC) |
| [TareaFruteria](TareaFruteria) | Frutería con sesiones: el cliente va anotando su pedido |
| [ImagenesTarjetas](ImagenesTarjetas) | Elegir forma de pago guardándola en una cookie y en una sesión |
| [EjercicioMiniCasino](EjercicioMiniCasino) | Minicasino de par/impar con sesiones y cookie de visitas |
| [TareaControlNotas](TareaControlNotas) | Tarea de control: consulta de notas con login, roles alumno/profesor y bloqueo tras 5 fallos |
| [EjercicioPOO](EjercicioPOO) | Ejercicios de Programación Orientada a Objetos (CuentaBancaria, Reloj y Coche) |

## Cómo probarlos
1. Copiar la carpeta del ejercicio en `htdocs` de XAMPP (o en la carpeta del servidor que uses).
2. Arrancar Apache.
3. Abrir en el navegador `http://localhost/<carpeta>/`.

Cada carpeta tiene su propio README explicando el ejercicio.
