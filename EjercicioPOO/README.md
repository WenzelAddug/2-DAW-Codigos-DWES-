# EjercicioPOO - Programación Orientada a Objetos en PHP

Ejercicios de POO en PHP. Las clases están completadas a partir del código que nos dio el profesor.

| Carpeta | Clase | Qué se practica |
|---|---|---|
| [Ejercicio1POO](Ejercicio1POO) | `CuentaBancaria` | Atributos privados, constructor con valor por defecto, atributo `static` |
| [Ejercicio2POO](Ejercicio2POO) | `Reloj` | Guardar la hora en segundos, formato 12/24 h y mejora con alarma |
| [Ejercicio3POO](Ejercicio3POO) | `Coche` | Métodos que devuelven `bool`, método privado `infoError`, array de objetos (carrera) |
| [Ejercicio4POO](Ejercicio4POO) | `BiciElectrica` | Métodos mágicos `__get`/`__set`/`__toString`, leer un CSV y buscar la bici más cercana |

Cada ejercicio tiene su clase, su archivo de prueba y su propio README.
