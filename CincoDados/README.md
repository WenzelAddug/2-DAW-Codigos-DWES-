# Cinco Dados

Juego de cinco dados entre dos jugadores, partiendo del código del profesor.

- Cada jugador tira 5 dados (números aleatorios del 1 al 6 con `rand`).
- Los dados se dibujan con los caracteres UTF-8 de los dados (&#9856; a &#9861;).
- Los puntos son la suma de los dados quitando el más alto y el más bajo.
- Al final se muestra quién ha ganado o si hay empate.

Archivo: `cinco-dados-v0.php` (cada vez que se recarga la página es una partida nueva).
