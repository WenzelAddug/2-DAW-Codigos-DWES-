# Soluciones de Profesor Alberto

En esta carpeta están los ejercicios y ejemplos de PHP que hemos hecho en clase de DWES con el profesor Alberto (curso 2026-2027).

**Ojo:** el código de aquí no es mío, son las **soluciones del profesor**. Mis propias versiones de los ejercicios están en las otras carpetas del repositorio.

La carpeta se va actualizando después de cada clase con él, así que puede que haya ejercicios que todavía no estén.

## Contenido

| Carpeta | Qué hay |
|---|---|
| `soluciones01` … `soluciones09` | Soluciones de cada boletín de ejercicios (en `soluciones09` está el control de BD `ControlDB-I`: login de clientes y listado de sus pedidos) |
| `ejemplosformularios` | Ejemplos de formularios |
| `POO_ejemplos` | Ejemplos de programación orientada a objetos (herencia, interfaces, traits, métodos mágicos...) |
| `BD_PDO_ejemplos` | Ejemplos de acceso a base de datos con PDO |
| `tareas` | Soluciones de las tareas (cinco dados, piedra papel tijera, casino, foro, frutería...) |
| `exam` | Control / examen |
| `testphp` | Prueba básica de PHP |
